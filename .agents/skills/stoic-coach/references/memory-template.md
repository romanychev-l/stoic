## Рабочие правила сопровождения

- Оценивать поведение, не личность.
- После нарушения продолжать практику без паузы.
- Давать одно корректирующее действие.
- Не считать отсутствие отчёта успехом.
- Не героизировать недосып, голод, боль или чрезмерную нагрузку.

## Протокол перехода

- [ ] подъём и действительно необходимое исключение;
- [ ] доступная разрешённая еда и вода;
- [ ] место для утреннего блока;
- [ ] возможность выполнить телесные практики;
- [ ] время для медитации;
- [ ] социальные планы и отбой;
- [ ] заранее созданная дневниковая заметка.

## Формат короткого отчёта

`Сон / подъём / утренний блок / правила на грани / питание / нагрузка / дневник / отбой / статус.`
